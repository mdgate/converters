About

          

            
One model

            

              Every format parses into the same document model
              and renders through the same Markdown serializer, so headings,
              nested lists, and tables come out the same from a .doc, an
              .eml, or yesterday’s .xlsx.
            

            
Detection

            

              The format is read from the bytes, not the extension, so
              mislabeled files still convert. Pass hint.path only
              for signature-less formats such as CSV, TSV, and plain text.
            

            
Portable

            

              The converters are TypeScript with no Node builtins. The same
              toMarkdown(bytes) call works in Node, Edge, and this
              page.
            

            
PDF

            

              Text-based PDFs convert locally. Scanned or image-only pages need
              OCR and are reported as unsupported.
            

            
This page

            

              The converter above is
              @mdgate/converters, running in a Web Worker. Drop a
              file into your own app the same way.

Local

            

              $
              npm install @mdgate/converters
            

            
Hosted API

            

              $
              npm install mdgate
            

          

          
import { toMarkdown } from '@mdgate/converters';

const bytes = new Uint8Array(await file.arrayBuffer());
const markdown = await toMarkdown(bytes, { path: file.name });
