About

          

            
One model

            

              A parser may build a Document and run the shared
              Markdown serializer,
              so headings, nested lists, and tables come out the same from
              a .doc, an .eml, or yesterday’s .xlsx.
            

            
Detection

            

              The format is read from the bytes, not the extension, so
              mislabeled files still convert. Pass hint.path only
              for signature-less formats such as CSV, TSV, and plain text.
            

            
Portable

            

              The converters are TypeScript with no Node builtins, no WASM,
              and no dependencies outside @mdgate/*.
              The same toMarkdown(bytes) call works in Node, Edge,
              and this page.
            

            
Formats

            

              One package per family, or the full bundle. The
              list above is what this page will convert.
            

            
PDF

            

              Text is extracted locally. Embedded images are handed to the
              converter pool when a vision callback is registered.
            

            
This page

            

              The converter above is
              @mdgate/converters, running in a Web Worker. Drop a file into your own app the
              same way.
            

          

        


        

          
Install

          

            
Everything

            

              $
              npm install @mdgate/converters
            

            
One format

            

              $
              npm install @mdgate/docx
            

          

          
import { toMarkdown } from '@mdgate/converters';

const bytes = new Uint8Array(await file.arrayBuffer());
const markdown = await toMarkdown(bytes, { path: file.name });

          

            The same function works in Node, Edge, and the browser. Compose a
            smaller set with create(), or hand images to a vision
            model. See the
            README.
